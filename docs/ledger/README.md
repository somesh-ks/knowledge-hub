# Design engineering ledger, by surface

The ledger was one 116 KB file; an agent doing UI work read all of it. It is now the core ([design-engineering-ledger.md](../design-engineering-ledger.md): taste, how to work, reversals, the phone) plus one file per surface here. Section numbers are kept, so "ledger section 3" and "section 8" still point somewhere.

| File | What it holds |
| --- | --- |
| [look-tokens-type.md](look-tokens-type.md) | Hand-written CSS, tokens, type, radii, the 8pt grid |
| [colour-theme-art.md](colour-theme-art.md) | Colour, light and dark, covers and art |
| [motion-navigation.md](motion-navigation.md) | Transitions, the nav pill, page and cover motion |
| [player.md](player.md) | The mini player, the full player, the queue, the sheets |
| [bottom-stack-phone.md](bottom-stack-phone.md) | Nav, mini player and sheets stacked at the foot of a phone |
| [components.md](components.md) | Buttons, chips, selects, dialogs, cards, one fix at a time |
| [reading-library.md](reading-library.md) | Digest and topic pages, the Library list |
| [settings-forms.md](settings-forms.md) | Settings, Preferences, forms and creation flows |
| [sound-accessibility.md](sound-accessibility.md) | Sound cues, haptics, reduced motion, focus, contrast |
| [code.md](code.md) | Sections 5 to 8: hacks and mechanisms, what the code does well, gaps in the code, owner asks with no record of being done |
| [ideas.md](ideas.md) | Sections 9 and 10: dreams, and the skill enrichment queue |

A new design ask goes in the surface file it changes, as a row with its decision number. Move an item out of the open asks in `code.md` once it is done.
