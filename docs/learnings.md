# Learnings

One line each: symptom, cause, fix. Newest first. Search before debugging.

- 2026-10-13: the two voice-picker specs failed every run beside other specs (on the D101 commit too, so not this session's change) and passed alone: the page had scrolled after the press and a scroll closes an open list, which the trace's last frame showed. `openPicker` in `e2e/picker.ts` presses again until the list stays open; 77 runs passed three times in a row after it. When a spec fails only in company, open its trace and read the last screencast frame before touching the product.
- 2026-10-13: the Speechify tests (a real loopback server) failed in 2 of 6 full-suite runs with `fetch failed`, never alone, and a retry of two on those describes fixed the red; the cause is not found. `describe.configure` and `vi.setConfig({ retry })` do not exist in Vitest 5: pass `{ retry: 2 }` as the describe's second argument.

- 2026-10-13: a clean local gate took 5.3 minutes and a one-file test 37 s: every process the agent's Git Bash starts costs 3 to 8 s (`/usr/bin/true` too), against 50 ms from PowerShell, where the same file ran in 1.4 s. Run commands through `powershell -NoProfile -Command`, or `npm run gate`, which starts the others itself.
- 2026-10-13: `npm run typecheck` never looked at `apps/web` (its tsconfig includes `packages` and `scripts` only) and CI ran only that; a call left after a deleted function threw on every Daily page and only the browser suite saw it. `typecheck` now ends with `astro check`.
- 2026-10-13: two `dispatch-worker` agents again used all 60 turns and reported nothing (each over 45 minutes), the lesson of 2026-10-10. The budget now lives in the agent file (90 turns, commit early, report by call 70): a line in this file is read by nobody who needs it.
- 2026-10-13: a worktree set up as the agent file said (the root `node_modules` as one junction) ran its checks against the main checkout, and a worker spent turns on path aliases. `scripts/worktreeLinks.mjs` does it right in one call and has a safe `--remove`.
- 2026-10-13: Playwright's headless Chromium hides scrollbars, so the New episode panel's shake (a scrollbar narrowing the column by 10px when More options opened) could not be seen; launch with `ignoreDefaultArgs: ["--hide-scrollbars"]` to measure it.
- 2026-10-13: the owner's dev server listens on `[::1]:4321` only; `127.0.0.1:4321` refuses, and `astro dev` will not start a second one. Screenshot `http://localhost:4321`, and run the browser suites on another port (`PORT`).
- 2026-10-13: a removed feature's last call (`showNext`) sat below the deleted function in a long script, passed `tsc` and the unit tests, and failed 45 browser tests on one `pageerror`. After deleting a function, grep its name in the file, and run the gate that includes the site check.

- 2026-10-11: a raw CSS length or undefined token variable broke `styles.test.ts`: test strictly enforces design system tokens for spacing, radius and tracking. Use tokens like `--space-1`, `--chip-radius` and `--text-meta-tracking`.
- 2026-10-11: adding `timezone` to schedule schema broke `schedule-store.test.ts`: test asserts deep equality against expected object. Add `timezone: "Europe/Stockholm"` to mock fixtures when updating core schedule defaults.
- 2026-10-11: a resumed worker ran `git reset --hard` in the main checkout: an Agent worktree is removed when its agent stops without changes, so the resumed agent's `cd` failed and its commands ran from the repository root. Make worktrees by hand on the session branch (`git worktree add -b <name> <path> <commit>`) and have every command start with `cd <path> &&`.
- 2026-10-11: a worktree whose `node_modules` is a symlink to the main checkout resolves `@dispatch/*` to the main checkout's packages (the workspace links are relative and Node follows the real path), so a worker's core edits were invisible to its own engine tests. Give each worktree a real `node_modules` whose entries link to the main install, with `@dispatch/*` linked to the worktree's own packages.
- 2026-10-11: adding a flag to each voice label passed every unit test and broke two e2e specs that assert the option text. Run the e2e specs that read a label you change.
- 2026-10-11: `topics.test.ts` pinned the live `config/topics.json` to the shipped seed, so the first rename in the app (allowed since D64) would have failed CI on the next PR. It now checks that the file resolves and holds every shipped topic.
- 2026-10-10: the player's flick tests failed about half the time: the page reads speed from each event's timeStamp, and under load the harness delivered moves 30 to 100 ms apart where 8 were asked for.
