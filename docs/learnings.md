## Browser tests

- 2026-10-19: a source just added showed as a tinted stub with no address, rating or checkbox, and its `box-shadow` tint spread 8px over the next row. The add specs checked text and the request, never the row's parts or box, and unit tests cannot see CSS. The new row is built from the same parts as a built row (`source.add` takes the page's `id`, so it is live at once) and the spec asserts those parts and no `box-shadow`. A row made in script must mirror its Astro component's markup; a state drawn by `box-shadow` or outline spreads past the box.

- 2026-10-12: a mocked route answers while the browser context is offline. A test of an offline save takes its mock offline with it (`route.abort`), and waits for the lazy chunk it needs before going offline.
- 2026-10-12: `waitForLoadState("networkidle")` returns at once when the page has been idle before, so a test went offline while a lazy chunk was still on its way (one run in four). Wait for the response itself, then `finished()`.

## Engine and workflows

- 2026-10-19: adding a YouTube channel in the panel said "The address could not be read". The preview caps a page at 1 MB and a channel page is about 1.3 MB, so the fetch threw, `resolveYoutubeChannel` swallowed it, and even a `/channel/UC...` address (which holds the id) failed. The id now comes from the path, then YouTube's `navigation/resolve_url` (about 1 KB), then the page. Firecrawl is not the YouTube path (its copy of a channel page carried a 401 banner); a social page with no feed (x, instagram, facebook, linkedin, tiktok, threads) is refused instead of becoming a scrape source.
- 2026-10-19: a YouTube finalist reached the writer with only its feed description, because `extractFullText` fetches a watch page that holds no speech. YouTube items now go through `extract/youtubeText.ts`: subtitles, then Gemini (`GEMINI_TRANSCRIBE_MODEL`, first 30 minutes, 3 per run), cached in `state/video-text.json`. Caption scraping reads the watch page, which YouTube can change; failure degrades to the description.
- 2026-10-19: the caption track URLs on a watch page answer 200 with an empty body, so every video fell through to Gemini. ## Site and service worker

- 2026-10-16: an installed Android web app keeps the manifest's theme_color from install and paints the system navigation bar in it (Chromium's WebAppNavigationBarThemeColor); a runtime theme-color meta never repaints it, and Chrome 128 dropped dark manifest colours. Leave theme_color out to get bars that follow the system theme.
- 2026-10-14: on mobile Chrome a fixed element held by its bottom edge moves with the address bar in the same frame, but one held by both edges (`inset: 0` or top and bottom) resizes only after the gesture ends. The player bar was held by both edges and the navigation and the floating button by their bottom, so they drifted apart and snapped back (#120). Hold every bottom-stack element by its bottom edge, and size a full-height fixed box with `100dvh`: its `100%` is the small viewport.
- 2026-10-11: Safari 27 has no `overlay`, so a closing dialog or popover leaves the top layer as its exit starts and the exit plays in the page: give top-layer elements their own `position` and a z-index (the top layer ignores it), and close at once under `@supports not (overlay: auto)` where an ancestor has a transform.
- 2026-10-11: the voice sample button never worked in production: it played Speechify's own URL, which the page's `media-src` blocks, and its error handler hid the button, so it looked like a missing feature. A media URL from a third party needs the CSP checked, or a same-origin route (`/api/voice-sample`).
- 2026-10-09: A move between destinations took 400 ms although the page was ready after 70: the mark that picks the move's animation (`data-astro-nav`) was lost in the swap, because Astro 7 keeps only its own fixed root attributes, not every `data-astro-*`. The designed transition had never run; the browser's default did. Carry a mark onto `event.newDocument` in `astro:before-swap`, and check what actually animates with `document.getAnimations()`.
- 2026-10-09: The first press after opening the app blocks for about 200 ms when the audio device has been idle, about 75 ms when warm: `new AudioContext()` inside the press. `latencyHint` and `sampleRate` do not help; a first measurement said they did, because whichever context is created first pays. Run the control with the order reversed.

## Windows and shells

- 2026-10-14: from the agent's Git Bash, `powershell -Command "..."` loses `$_`, `$env:` and `$LASTEXITCODE` to bash, and an argument or variable that starts with `/` is rewritten to a Windows path. Put PowerShell with variables in a `.ps1` file and run it with `-File`; pass several paths as one string to split, since `-File` does not pass an array.
- 2026-10-14: `pkill -f serve.mjs` inside a Bash call killed that call's own shell, whose command line matched. Kill by PID from a filtered `ps`.
- 2026-10-12: a committed unit test failed because a truncated `tail` of the vitest output looked like a pass. Read the "Test Files" and "Tests" lines for `failed` before committing.
- 2026-10-12: heredoc or `node -e` edit scripts lose backslashes and abort on backticks in the agent shell (`/\/+$/` arrived as `//+$/`), and some worker worktrees refuse compound commands, heredocs and `$VAR` arguments. Write scripts to files with the Write tool, use plain single commands, and make multi-edit scripts all-or-nothing.
- 2026-10-11: the sandbox proxy refuses news hosts (403 to CONNECT), so `curl` cannot check a feed. Fetch it with Firecrawl's scrape (`rawHtml`, a week's `maxAge`), in a subagent so the bodies stay out of the session; Firecrawl allowed about ten requests a minute.
- 2026-10-09: Ports 4524 to 4623 are reserved by Windows on this machine (`listen EACCES`); `netsh interface ipv4 show excludedportrange protocol=tcp` lists them. Use 47xx.
- 2026-10-08: `npx` sometimes stalls for a minute on this machine before running a local binary; a stalled command is not a failed one, and reading its output file is quicker than rerunning it.
- 2026-10-08: 37 GB of a full disk was one other project's Claude temp folder under `%TEMP%\claude`; this repository with its dependencies is under 600 MB. Measure before deleting.

## Agents and worktrees

- 2026-10-16: a worktree's `node_modules` symlink was committed (the ignore rule `node_modules/` matches directories only), and merging that branch replaced the real, ignored `apps/web/node_modules` with it: git overwrites ignored paths. The rule is now `node_modules`; after such a merge, run `npm ci`.
- 2026-10-16: `scripts/worktreeLinks.mjs --remove` fails on Linux with ENOTDIR on the symlinks it made; remove them with `rm` before committing from a worktree.
- 2026-10-14: squash-merged branches never pass `git branch -d` (their commits are not ancestors of main), and the auto-mode classifier refuses `-D`. Prove a branch is merged by matching its commit subjects against main's squash bodies, keep a `git bundle` of the heads in `.git/`, and let the owner run the force delete.
- 2026-10-12: cherry-pick a worker's non-merge commits (`git log --no-merges --reverse <lead>..<branch>`) and run `biome check` again afterwards: a formatting difference between two branches shows only on the combined tree.
- 2026-10-11: the Claude Code review workflow's code-review plugin stops at a PR it has already reviewed, so after a "No issues found" a re-labelled run checks in 4 turns, posts nothing and reports success, and new commits go unreviewed. Read the run's turn count, and review new commits another way (a local `/code-review` on the range).
- 2026-10-06: Auto-mode classifier blocks credential creation, store deletion and merging unreviewed PRs; the owner runs those.
