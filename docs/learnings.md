# Learnings

One line each: symptom, cause, fix. Newest first. Search before debugging.

- 2026-10-10: a long-lived static test server kept the fixture stubs it started with (no `/api/voices`), so a whole suite failed (112 tests) on pages that fetch it. Restart the server before a suite that follows a change to `e2e/staticServer.mjs`; check `curl` on the new route first.
- 2026-10-10: `git checkout <branch> --autostash` is not a flag; the checkout failed quietly and a whole verification ran on the wrong branch. Print `git branch --show-current` before and after a switch that a result depends on.
- 2026-10-10: `secrets:push` failed all 8 Vercel targets with "Could not retrieve Project Settings": the script passed the `.env` `VERCEL_TOKEN` (the GitHub Actions token, dead) to a CLI whose login worked, and it hid stderr. Let the CLI use its own login; show the first meaningful stderr line with every `.env` value masked.
- 2026-10-10: the lab pages shipped in production (36 KB each): a `return new Response(404)` guard inside a page does not stop a static build from writing it. Inject dev-only routes from `astro.config.mjs` (`injectRoute` when `command === "dev"`), and check the build output for the path.
- 2026-10-10: a hero cover under the open player's header started a native image drag on a mouse press (`dragstart`, then `pointercancel`), so a flick down did not close the page; and the modal scope exempted every body child holding a `[popover]`, so the page behind stayed reachable by Tab once the More menu became a popover. Covers are `draggable="false"`; only `[popover=manual]` (the toast) is exempt.
- 2026-10-10: Lint was red on main for every PR because the engine writes `state/last-run.json` in a format Biome rejects; Biome now skips `state/`. A check that fails on files nobody edits by hand is a config bug, not a formatting chore.
- 2026-10-10: a script that centres the first turn on mount scrolled a one-column page 388px past the cover. Do not scroll on first render; follow when the thing being followed changes.
- 2026-10-10: scaling a text control on press (`transform: scale`) makes the words smaller and re-draws their weight; the owner flagged it on the theme segments. Selection controls show a press on the thumb or colour; `pressText.test.ts` enforces it.
- 2026-10-10: `audio-speechify.test.ts` fails one case at random when other suites run beside it and passes alone; rerun it alone before blaming a change.
- 2026-10-10: removing a worktree whose `node_modules` holds junctions: `node unlink-links.mjs <dir>` (lstat walk, `rmdirSync` on each link, never descends a link, exits 1 if any remain), then `git worktree remove --force --force`. Ten worktrees were removed this way with the main `node_modules` still at 319 entries. A worker's leftover static server holds its worktree (Permission denied); find it with `netstat` and stop that pid.

- A decoration that passed every gate on its own branch was cut in a straight line after a rebase: another branch had moved the header's top spacing into the header, so a layer placed relative to it started 32px higher. Suites compare behaviour, not looks; after a rebase onto a visual change, look at the page again.
- A masked layer showed a line one device pixel thick at its edge, 2 to 4 levels off: Chromium on a GPU leaves the outermost row of a masked box unmasked. `clip-path: inset(1px)` removes it. Screenshots hid it; reading pixel values down a column found it.
- A browser spec passed against a stylesheet that had just been changed: a static server from an earlier step was still listening, so Playwright reused it and skipped the build. In Git Bash `kill $!` does not stop a Windows `node`; find the pid with `netstat -ano` and use `taskkill`, and confirm the port is free before a run that must rebuild.
- A move between destinations took 400 ms although the page was ready after 70: the mark that picks the move's animation (`data-astro-nav`) was lost in the swap, because Astro 7 keeps only its own fixed root attributes, not every `data-astro-*`. The designed transition had never run; the browser's default did. Carry a mark onto `event.newDocument` in `astro:before-swap`, and check what actually animates with `document.getAnimations()`.
- The settle into a briefing never showed: its rule weighed less than the rule for every move, which carried a `:not()`. A rule meant to override must weigh at least as much and come later; `viewTransitions.test.ts` pins it.
- A mark set on the live root before the swap animated the page that was leaving. Set it on the incoming document only.
- A decorative layer reached 48px past the header; on a phone that made Today 422px wide, the navigation could not be tapped and transitions aborted with "Viewport size changed". Its browser test pressed the navigation from script and filtered the error out, with comments blaming the phone emulation. Compare with a build that lacks the change before calling something an emulation quirk; treat an excused error or a scripted press in a test as a finding.
- A contrast proof passed because it left out the one accent-coloured text in the header, which failed on every palette. Ask what else sits on the thing before trusting a proof about it.
- A WebGL canvas made the player suite fail on every page: headless Chromium draws on the processor (SwiftShader) and logs "GPU stall due to ReadPixels" each frame, and that suite fails on any warning. `failIfMajorPerformanceCaveat` does not refuse that context. Read the renderer's name from a scratch canvas (`WEBGL_debug_renderer_info`) and skip WebGL on a software one.
- The test written for that fix passed while the bug was still there: it waited 500 ms and the warning comes later. Run a new test against the build without the fix and see it fail first.
- The site suite cannot run with `--headed` on this machine: Kaspersky injects requests that the page's CSP blocks, and the fixture fails on any console error. Check GPU-only behaviour with a standalone script that ignores those lines and nothing else.
- gitleaks failed a pull request on an invented key in a test (`nb-secret-key-...`). Use a value `.gitleaks.toml` already allows (`key-123456789`) instead of widening the allowlist.
- The first press after opening the app blocks for about 200 ms when the audio device has been idle, about 75 ms when warm: `new AudioContext()` inside the press. `latencyHint` and `sampleRate` do not help; a first measurement said they did, because whichever context is created first pays. Run the control with the order reversed.
- A browser test that read animations one frame after the swap failed under load, because the marks come off after 200 ms. Read inside the page, at the event.
- A test run piped through `grep` or `tail` reports the filter's exit code, which is 0. Record `$?` of the runner itself.
- Ports 4524 to 4623 are reserved by Windows on this machine (`listen EACCES`); `netsh interface ipv4 show excludedportrange protocol=tcp` lists them. Use 47xx.
- The player suite can run its `site-*` projects in a worktree without a dev server: serve the fixture build, and set `PLAYER_LAB_URL` and `PLAYER_SITE_URL` to it. Run that way, six tests fail on `main` as of `f229931` (`gestures.spec.ts:228` and `stuck.spec.ts:95` on both phone projects, `gestures.spec.ts:67` and `stuck.spec.ts:95` on desktop).
- Three `dispatch-worker` briefs of a night's size all stopped at 60 turns without a report. Plan for the resume, or split the brief.
- A probe of freshly edited agents showed the old behavior (`rm` allowed, `Explore` with every MCP tool): agent files are read at session start. Restart the session before testing an agent definition.
- The built-in `Explore` carried every MCP tool family, and a three-call lookup used about 275k subagent tokens; a `reviewer` probe of the same size used 13k. Restrict `tools` on any agent that does not need MCP.
- `docs/build-plan.md` says a 100 KB first-load budget; the enforced value is 102 KB in `apps/web/src/lib/bundleBudget.ts`. Trust the constant.
- Create, Generate and saving topics all answered "not available right now" on production: the site's fine-grained GitHub token was valid but had no access to this repository, so GitHub answered 404 for the repo, its workflows and its runs. `doctor --online` does not check `GITHUB_DISPATCH_TOKEN`; it should.
- A discussion episode had one voice: `SPEECHIFY_VOICE_ID_B` was read but set nowhere, not in `.env.example` and not in `secrets:push`. A setting a feature depends on needs a default or a place in the setup path.
- Browser suites showed failures from another session's build: every session writes `apps/web/dist`. A page reading "10 stories" in a fixture run is the real briefing; rerun, and give each session its own worktree.
- Hidden elements rendered on four pages (an error icon with no error, a save bar with nothing to save): the `[hidden]` rule relied on being imported last, and the build reorders stylesheet chunks. The rule now carries an id's weight, and `e2e/hidden.spec.ts` checks every built page.
- Flick tests failed about one run in seven: the harness asks for 8 ms between touch moves and the page receives them 30 to 50 ms apart, which put a six-step flick on the velocity threshold. Synthesize a flick in three large steps, and log the events the page received before blaming the gesture code.
- Every lab test failed with `_jsxDEV is not a function`: the dev server's dependency cache went stale while a build ran beside it. Delete `apps/web/node_modules/.vite/deps` and start the dev server on its own.
- A wide-only control showed on phones: `.dock-wide { display: none }` lost to a later `.dock-btn { display: grid }` at the same weight. A hide rule needs more weight than the rule that sets the display.
- Both browser suites reported failures that were not real: `reuseExistingServer` picked up a preview server on 4321 serving an older build. Stop any preview server before running a suite.
- A page's script did nothing after a client-side navigation: Vite inlined the small module as a `data:` script, which the CSP blocks. `vite.build.assetsInlineLimit: 0` keeps every page script a file.
- The Library page shipped 135 KB of JavaScript: its script imported a pure helper from a module that also imported build-time code (`digestView`). Keep what a page script imports in a module with no build-time imports.
- A merge was refused with "local changes would be overwritten" because an agent had staged work in the main checkout. Agents that share the main checkout commit before any merge; otherwise give them a worktree.
- A function's budget counter could lose counts: `@vercel/blob` honours `useCache: false` only for private stores, and this store is public, so a state read could be a minute stale. Read mutable state with `head()` and then the URL plus a version query built from what `head` returned.
- Vercel Hobby includes 2,000 advanced Blob operations a month (`put`, `copy`, `list`) and 10,000 simple ones (`head`, a read that misses the cache); going over locks the store for 30 days. Count operations per call when designing anything that writes to Blob, and never `list` on a page view.
- The live Play control never changed to Pause: the page rendered `.cta-label` while `readerSync` wrote to `[data-play-label]`, and every player test ran against the dev lab page, which had the right hooks. Test the contract between markup and script on a real built page.
- The disk filled (0 bytes free) when two agents each ran `npm ci` in their own worktree. Give a worktree junctions into the main `node_modules` instead, and never install inside one.
- `npm run lint` fails inside a worktree under `.claude/`: `biome.json` ignores `**/.claude`, so Biome ignores `.` there. Run `npx biome check apps packages scripts tokens` in the worktree and the full lint from the main checkout.
- An inline `node -e` or heredoc script lost its backslashes in the agent shell (a regex `/\/+$/` arrived as `//+$/`). Write any script that contains a backslash to a file first.

- Blob upload failed with "OIDC is enabled for this project, but not for the development environment": the CLI pull issues a development OIDC token and the store was connected to Production and Preview only. Connect the store to Development too (dashboard, Storage, store, connected project, environments).
- `audio.yml` failed at the write guard ("changes outside the publish allowlist: .gitignore"): `vercel link` and `vercel env pull` edit `.gitignore` and write `.vercel`; run them in a scratch directory outside the checkout.
- `vercel env pull` writes the text `[SENSITIVE]` for hidden secrets, so `BLOB_READ_WRITE_TOKEN` would load as that string and beat the OIDC credentials; `loadEnv` now treats it as unset.
- Doctor said voice `geffen_32` was missing: Speechify `GET /v1/voices` is cursor-paged (50 by default, 200 at most); follow `next_cursor` while `has_more` is true.
- Green tests did not catch the audio failure: nothing exercises the live Vercel, Speechify and Blob path. Run `dispatch doctor --online` after any credential change.
- First `audio.yml` run (2026-10-06) failed at `vercel link` with "User not found (404)": the `VERCEL_TOKEN` secret is invalid or the wrong kind. Replace it with a fresh account token from the dashboard, then rerun the workflow.
- Run failed at Commit with a change outside the write allowlist: `npm ci` marks `packages/engine/src/cli.ts` (a `bin` target) executable. Track it as 100755.
- Vercel Hobby blocks deploys of bot-authored commits: only the team owner's commits deploy. Engine commits as `DISPATCH_GIT_NAME` and `DISPATCH_GIT_EMAIL` (D25).
- Vercel Blob token cannot be copied: it is sensitive and hidden after creation; use OIDC credentials (D26).
- `vercel tokens create --project` fails on Hobby ("Cannot create tokens for this app"): create an account token in the dashboard.
- The Vercel CLI appends `.env*` to `.gitignore`, which would ignore `.env.example`. Revert it before committing.
- `vercel env add` failed when run from `apps/web` but the project was linked at the root: `secrets:push` now uses whichever directory has `.vercel/project.json`.
- gitleaks needs `pull-requests: read` on pull requests.
- Biome lints Playwright `test-results`; excluded in `biome.json`.
- Stylesheet test assumed the layout imports every CSS file; islands import `player.css` too.
- Write step skipped the grounding check because `TYPESAFE_API_KEY` was missing from its env.
- `astro check` crashes on TypeScript 7: pinned to 6.x (D19). Dependabot ignores major versions.
- Local Windows builds of the Vercel adapter fail on symlinks: use `DISPATCH_STATIC_ONLY=1`.
- Nebius model ids change; take them from `dispatch models`, not docs (D24).
- Auto-mode classifier blocks credential creation, store deletion and merging unreviewed PRs; the owner runs those.
- 2026-10-08: heredoc-built edit scripts with backticks or backslashes aborted the shell; write them with the Write tool. A test that misfiles a story into a retired section no longer fails validation, because published briefings must still validate; use a live section instead.
- 2026-10-08: a worktree whose `node_modules` is a junction to the main checkout resolves `@dispatch/*` to the main checkout sources, so new core exports are missing in tests; build a real `node_modules` of per-package junctions with `@dispatch/*` pointing at the worktree. A 5 minute episode came out at 2 minutes because the prompt gave a ceiling and nothing rejected a short script (D43: floor of 80 percent). An episode for "Design" was made of top picks alone because they always matched (D43: empty topics are named, all-empty fails).

- A worktree whose `node_modules` is a junction to the main checkout resolves `@dispatch/core` to the main checkout, so core edits are invisible to tsc and tests; link each package separately and point `@dispatch/*` at the worktree.
- The shell tool refused some multi-command heredocs and `cmd` calls in a worktree; use the Edit and Write tools and plain single commands.
- `npx vitest` and `npx tsc` do nothing useful in a worktree whose `node_modules` has no `.bin`; run `node node_modules/vitest/vitest.mjs` and `node node_modules/typescript/bin/tsc` directly.
- A commit that adds one file and removes a similar one shows as a rename; pass `--no-renames` to `show` when a test checks a replace commit.
- 2026-10-08: `git worktree remove --force` (and `rm -rf`) on a worktree whose `node_modules` holds junctions follows them and deletes the main checkout's packages; it emptied `node_modules/.bin` and two `@astrojs` packages. Remove each junction as a link first (`cmd //c "rmdir <path>"`, no `/s`), and never ask a subagent to remove a worktree. Repair: `npm rebuild --ignore-scripts`, then `npm install --ignore-scripts`.
- 2026-10-08: a dev server left running across an install serves mismatched React builds, and every island fails with `_jsxDEV is not a function`. Astro refuses a second dev server for the same project; stop the old one with `npx astro dev stop`.
- 2026-10-08: a writer told a length in characters delivers a third to two thirds of it; told in words, per story and in total, it delivers 83 to 90%. A script also cannot be longer than its stories can carry, so hold it to that and not to the request.
- 2026-10-08: a limit nobody asked for is a bug waiting for its first user: two episodes a day stopped the owner on the first day. Tests that hard-code a policy number (a cooldown of 30 minutes) break when the policy moves; compute from the constant.
- 2026-10-08: in one stylesheet, a media block placed before the base rules it changes loses at equal specificity. Put the override after the rules it overrides.
- 2026-10-08: `npx` sometimes stalls for a minute on this machine before running a local binary; a stalled command is not a failed one, and reading its output file is quicker than rerunning it.
- 2026-10-08: during a view transition the page is drawn as images in an overlay that takes the pointer, so the cursor flickers to the arrow over a link and a press is lost. `::view-transition { pointer-events: none; }` fixes it; a style test keeps the rule.
- 2026-10-08: a tab left open across a deploy asks for lazy script files the deploy removed; the player's controls and narration then fail quietly. Listen for `vite:preloadError`, drop saved pages and reload once, but not while offline.
- 2026-10-08: the service worker followed script imports only three levels deep when saving the shell, so each new lazy import pushed another file out of the offline copy and broke the offline specs. Follow them deep (six) and bump the cache version.
- 2026-10-10: the bundler writes a lazy import with a backtick quote (import(`./x.js`)), which the service worker's reference patterns missed, so the lazy file was not saved. The patterns accept backticks now; VERSION v5.
- 2026-10-08: a background request made on page load (the narration prewarm) reaches the fixture server in every browser test and fails the "no console errors" rule. Decide how the fixture answers it before merging.
- 2026-10-08: `getByRole("button", { name: "All" })` matched "Gallery view". Use `exact: true` for short names.
- 2026-10-08: a glyph listed only for the lazy icon set renders nothing through the eager `Icon`; `tsc` passes and only `astro check` catches it. Run `astro check` before a PR: CI does not.
- 2026-10-08: branches that each pass alone can fail together (tab order, focus ring, touch targets, bundle size). Stack them and run the whole site suite before the PR, and measure the bundle on the stack.
- 2026-10-08: 37 GB of a full disk was one other project's Claude temp folder under `%TEMP%\claude`; this repository with its dependencies is under 600 MB. Measure before deleting.
