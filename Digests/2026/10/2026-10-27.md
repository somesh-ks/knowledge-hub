### [A Cloudflare bug leaked other customers' data in 155 GLM-5.3 responses](https://blog.cloudflare.com/kv-cache-exposure-remediation)
Cloudflare Blog, Kevin Flansburg, Michelle Chen

Cloudflare says 155 responses from its GLM-5.3 model on Workers AI included other customers' data between August 27 and September 9, 2026. All answered prompts longer than 681,280 tokens, the most its cache pool held, although the context window was 1,048,576. A bug in the SGLang inference engine let oversized requests read stale cache pages instead of returning an error. Cloudflare knew of the mismatch before launch but had only checked response codes.

### [OpenAI's GPT-6.1 Terra is a faster midrange model at half the price](https://simonwillison.net/2026/Oct/26/gpt-61-terra)
Simon Willison

OpenAI released GPT-6.1 Terra, a fast midrange model for visual reasoning, computer use and clearer writing. It costs $1 per million input tokens and $5 per million output, almost half of GPT-5.6 Terra or Sol, and about ten times GPT-6 Luna. OpenAI's Ted Sanders says it beats Astra and Sol at technical communication and matches them on vision and computer use, much faster. It is a bit worse on most other things.

### [shadcn's MCP server moves to SDK v2 and changes its export](https://github.com/shadcn-ui/ui/releases/tag/shadcn%404.23.0)
shadcn/ui, github-actions[bot]

shadcn 4.23.0 moves its MCP (Model Context Protocol) server to version 2 of the MCP TypeScript SDK. The server now speaks the 2026-07-28 revision of the protocol as well as earlier ones. The shadcn/mcp export is now an McpServer, and a new createServer() export returns a fresh instance for each connection. Code that called setRequestHandler on the old Server export must switch to registerTool or server.server.setRequestHandler.
