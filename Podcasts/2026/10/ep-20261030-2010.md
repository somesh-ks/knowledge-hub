# Design engineering craft, Css canvas motion techniques and 1 more

This is Singularity, your briefing on tech and design. Today: Drupal proposes a color type for design tokens. Then shadcn/ui, design token standards, token cleanup, Atomic Design, Tailwind, Cloudflare, a UX glossary, CSS masonry, gradients, Gemini, and Copilot.

Drupal's Design Tokens API is getting a Color value type. A proposal says it must come before Border, Shadow and Gradient, because those are built from colors. It follows the DTCG 2025.10 spec, which stores a color as a color space, three channel values and an optional alpha. CSS comes out as oklch() or color(). A malformed color is rejected without breaking token discovery. The issue remains at implement and review, so the details are not final.

shadcn/ui shipped Trace and Code Block components, along with AI Elements. AI Elements is a set of patterns for interfaces that agents work inside. Examples include tool-call traces and streamed output. All of it covers Base UI, React Aria and Radix, the component foundations, across its styles. Projects still on Radix are not left behind, after shadcn/ui made Base UI its default earlier this year.

The Design Tokens Community Group published the first stable Design Tokens specification, numbered 2025.10, on October 28, 2025. Many editors and authors built the vendor-neutral file format. Figma, Sketch and Framer support it or are implementing it. Before this, each tool spoke its own dialect. Syncing is still the weak link. In Supernova's 2024 survey, 44.4% of teams ran design-to-code by hand, against 31.4% automated.

A team whose color palette everyone only partly followed rebuilt its design tokens. It renamed tokens by intent, such as surface-raised and text-muted, instead of by hue, such as gray-200. It deleted every token with no usages. It also added a CI check, an automated test, that fails on raw hex values in components. The system now feels smaller and easier to extend. Fewer options made the interface more consistent.

An essay on UX Collective proposes entering Atomic Design from the screen, by asking what each user action changes. A sort button sits in one column header but reorders the whole table, so position is a poor guide to what connects. The author puts shared rules, such as a filter change resetting pagination, in the template level. The scope breakdown is not universal, because scopes differ between screens and products.

A Modeinspect guide traces one design token from Figma to a Tailwind class. The path runs through a JSON export, CSS variables, theme mapping, and then the class itself. The theme owns the names and values. A Figma export seeds it once, and later exports arrive as reviewed diffs. Going back from code to Figma stays manual for most teams. Automating the sync through Figma's variables API needs an Enterprise Full seat.

Cloudflare released Origin Range Requests, a self-service feature on all plans that caches partial file requests. There is no range size to configure. The old design could pull 128 MiB from the origin for one small seek. On R2, Cloudflare's object storage, p99 time to first byte dropped by about half, and tiered cache traffic fell about 6%. A request smaller than a chunk can still fetch the whole chunk.

Nielsen Norman Group published a glossary defining UX design, UI design, visual design, interaction design, service design, UX research and DesignOps. It says people use UX, UI, CX and visual design as if they meant the same thing. Its UX-careers survey found 134 unique job titles related to UX. Titles are not standardized, so the boundaries are typical ones. One person in an organization may cover several areas.

CSS now has native masonry, the layout where items pack into columns of uneven height. It goes by the name display: grid-lanes. The CSS Working Group agreed in January 2025 to reuse Grid's track properties, and settled on the name by December 2025. Define columns with grid-template-columns and the browser places each item, usually in the shortest lane. No item heights are needed. The spec is still an Editor's Draft, so details can change.

Backgrounds Supply's Gradient Lab is a free browser tool that makes animated gradient backgrounds from more than 20 live shader modes. Video exports as MP4 or WebM at up to 4K and up to 30 seconds, with no watermark or account. Settings live in the page URL, so a link reopens the same gradient. An embed code runs it live in an iframe, so there are no video files to host.

That's Singularity for today. Thanks for listening.
