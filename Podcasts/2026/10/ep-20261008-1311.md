# Design

A: This is Singularity.

B: What is the Modern design system doing with DESIGN.md and tokens.css?

A: It separates design intent in DESIGN.md from implementation in tokens.css. Semantic tokens are compiled to Tailwind v4 and used in component manifests for validation.

B: So DESIGN.md defines what the design should do, and tokens.css handles how it works in code.

A: The system uses predefined scales for color, typography, and spacing, with hover states based on OKLab.

B: OKLab helps create more natural color shifts for interactions like hovering.

A: The @shadcn/registry now loads ts-morph only when adding new items.

B: Does that reduce the bundle size?

A: Yes, it cuts the read-only bundle size by 6 MB. Patch updates allow transformers for fonts, RTL, and CSS variables without ts-morph.

B: That makes the tool faster when you're just reading or using existing items.

A: Amazon Style Dictionary now maps design tokens to Tailwind CSS.

B: What does that let teams do?

A: It enables consistent color, spacing, and typography across different platforms.

B: Design systems can now align with utility-first CSS frameworks more easily.

A: Teams completed two sprints to reduce component variants and set a minimal token set.

B: How did they manage the changes safely?

A: They used archival pages and pairing sessions for safe, collaborative updates across Figma and code.

B: This helps prevent breaking designs while cleaning up outdated options.

A: CSS linear easing now supports multiple stops connected by straight segments.

B: Can this create motion effects that weren't possible before?

A: Yes, it enables spring and bounce effects that cubic-bezier cannot produce. Stops can be auto-spaced or set at exact percentages.

B: This gives designers more control over animation timing.

A: shadcn/ui 4.21.2 now supports UTF-8 BOM in config files.

B: What else is in this patch?

A: It includes a smaller custom config reader and skips npm audit and funding checks during installs. It was released yesterday.

B: This speeds up installation and improves config handling for some file encodings.

A: That's all for this episode.
