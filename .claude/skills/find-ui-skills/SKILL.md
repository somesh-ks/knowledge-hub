Whenever you are given a task related to frontend UI, design craft, typography, accessibility, or motion, you should proactively check if there are specialized skills available in the `ui-skills` library to help guide your implementation.

## Workflow

To find and download the right design intelligence for your current task, follow these steps:

1. **Find Categories**: 
   Run `npx ui-skills categories` to see the available design domains (e.g., animation, accessibility, typography, react).
   
2. **Find Specific Skills**: 
   Run `npx ui-skills list --category <category>` to see the specific skills available within a relevant category.

3. **Install the Skill**: 
   Run `npx ui-skills get <skill-slug>` to download the relevant skill directly into the project. This will typically place the skill instructions into the local workspace so you can read them.

4. **Absorb the Knowledge**: 
   Read the newly fetched skill file to absorb the specialized design engineering guidelines BEFORE writing or refactoring any frontend code.

Always rely on these expert-written skills to ensure you produce the highest quality, production-grade user interfaces that avoid generic or sloppy UI output.
